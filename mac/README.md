# KotaTask для macOS

Нативная копия Android-приложения KotaTask: SwiftUI, macOS 26 (Tahoe), локальные данные без синхронизации.
План и решения — [`docs/superpowers/plans/2026-10-22-kotatask-mac-port.md`](../docs/superpowers/plans/2026-10-22-kotatask-mac-port.md).

## Установка

```bash
./install.sh --open
```

Скрипт собирает Release, кладёт `KotaTask.app` в `~/Applications` и запускает. Нужны Xcode 26 и XcodeGen
(`brew install xcodegen`). Подпись ad-hoc — приложение для этого Mac, без App Store и нотаризации.

## Разработка

```bash
xcodegen generate                       # project.yml — источник правды, .xcodeproj не коммитится
open KotaTaskMac.xcodeproj
xcodebuild test -project KotaTaskMac.xcodeproj -scheme KotaTaskMac -destination 'platform=macOS'
```

Отладка на демо-данных, не трогая настоящие (только Debug-сборка): переменная `KOTATASK_DATA_DIR`
указывает отдельную папку данных, настройки тогда берутся из домена `KotaTask.Sandbox`.
Debug-сборка — отдельное приложение «KotaTask Debug» (`ru.kotadevelopment.kotatask.mac.debug`):
со своими настройками и уведомлениями, она не путается с установленной копией.

## Доска и подзадачи

- **«Сегодня»** — отдельный лист. **«Проекты»** — лист каждого проекта и «Общий», где проекты стоят колонками
  («Без проекта» всегда первая). Порядок внутри колонок ручной, задачи и колонки переставляются перетаскиванием;
  карточку можно бросить на «Сегодня» или на проект в сайдбаре.
- **Подзадачи** — полноценные задачи в один уровень. Бросок карточки в середину другой делает её подзадачей,
  вынос в колонку — отдельной задачей. Подзадачи всегда в проекте родителя и переезжают вместе с ним.
- **Время.** Задано у родителя — «Большая задача», оно главное. Не задано — «Блок задач»: время равно сумме
  открытых подзадач. В нагрузке дня ничего не считается дважды.
- Новые задачи и подзадачи создаются строкой «+ Новая задача» / «+ Подзадача» (⏎ — следующая).
- Каждое действие отменяется ⌘Z. Перетаскивание карточки — за её верх (заголовок и чипы); строки подзадач
  тащатся сами по себе.

Спека и план: [`docs/superpowers/specs/2026-10-22-mac-board-subtasks-design.md`](../docs/superpowers/specs/2026-10-22-mac-board-subtasks-design.md),
[`docs/superpowers/plans/2026-10-24-mac-board-subtasks.md`](../docs/superpowers/plans/2026-10-24-mac-board-subtasks.md).

## Где что лежит

| Папка | Что внутри |
|---|---|
| `Model/` | `TaskItem`, `Category`, `Day` (день без времени), перечисления |
| `Logic/` | Чистая логика: алгоритм приоритета, сортировки, валидация формы, сетка календаря, план уведомлений; `TaskTree` (подзадачи и итоговое время), `ManualOrder` (ручной порядок), `BoardQueries` (колонки доски), `DropGeometry` (куда упадёт карточка) |
| `Store/` | `TaskStore` (CRUD + ⌘Z), `TaskStore+Board` (операции доски), `Persistence` (JSON + 7 ежедневных копий), `AppSettings` (ключи Android) |
| `Services/` | Уведомления, смена дня |
| `Design/` | Палитра бренда, пружины, общие компоненты |
| `Views/` | Экраны |

## Данные

`~/Library/Application Support/KotaTask/kotatask.json` плюс `Backups/` с копиями за последние 7 дней.
Поля задач совместимы с форматом Android-бэкапа (`kotatask_backup.json`, версия 2). Доска добавила поля
`parentId`, `sortIndex` и необязательную `duration`; файлы без них читаются как раньше, а при первом запуске
новой версии ручной порядок засевается тем, что было видно в стеке.
Повреждённый файл не перезаписывается: он откладывается рядом, а задачи поднимаются из последней копии.
