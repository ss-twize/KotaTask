# KotaTask

## Суть проекта
Мобильный таск-менеджер с гибкой настройкой под пользователя.
Методики: GTD, time-blocking и др. Цель — быть удобнее бумаги.
Цель роста: 1000 премиум-подписчиков за 3 месяца.
Текущий этап: конец MVP, подготовка к бета-тестированию.

## Карта вики (не читать автоматически)
- wiki/decisions/   — ADR: принятые решения
- wiki/concepts/    — ключевые понятия проекта
- wiki/processes/   — процессы и воркфлоу
- wiki/status/      — текущий прогресс
- raw/inbox/        — необработанные материалы

## Соглашения
- Язык: русский
- Решения: формат ADR (контекст → решение → последствия)
- Ссылки между статьями: [[двойные скобки]]
- Имена файлов: YYYY-MM-DD-название.md

## Текущий фокус
Доделывание приложения + раздача знакомым для первой обратной связи.

## Правило работы с вики
Читай только файлы которые напрямую нужны для текущей задачи.
Не читай папки целиком если нужен один файл.
Если задача не требует контекста из вики — не читай ничего.
