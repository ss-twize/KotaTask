# KotaTask для macOS — план порта (v2)

**Дата:** 2026-10-22
**Цель:** полностью рабочая копия Android-приложения KotaTask для MacBook. Локальный запуск,
без синхронизации. Адаптивный интерфейс под размер окна, плавные анимации и материалы в духе Apple.

Заменяет план и спеку от 2026-06-01: тот прототип придумал другую модель данных
(срочность/усилие 1–5, статусы todo/inProgress/done, дневной лимит в штуках) и копией
Android-версии не был. Старый код остаётся в git-истории.

---

## 1. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| UI | SwiftUI, `NavigationSplitView` | Нативный Mac-каркас, сайдбар сам сворачивается на узком окне |
| Минимальная macOS | **26 (Tahoe)** | Машина пользователя на 26.5; Liquid Glass без `#available`-веток |
| Язык | Swift 6, изоляция по умолчанию `MainActor` | Строгая конкурентность без шума |
| Проект | XcodeGen (`project.yml` — источник правды) | Как и раньше в `mac/` |
| Данные | JSON-файл в `~/Library/Application Support/KotaTask/` | Атомарная запись, нет миграций схемы, которые могут уронить старт |
| Страховка данных | Ежедневная копия файла, хранится 7 штук | Аналог Auto Backup; Time Machine тоже видит папку |
| Настройки | `UserDefaults` с теми же ключами, что в Android (`coeff_deadline`, `feat_defer`…) | Паритет с ADR-003 |
| Шрифт | Системный SF Pro | Apple-ощущение; Manrope — только Android |
| Палитра | Бренд Android (Jordy Blue / Carnation / Paris Daisy / Sulu + нейтрали) в светлой и тёмной теме | Это копия, не редизайн |

## 2. Паритет функций (всё из Android)

- **Задача:** название, начало дедлайна, дедлайн, важность (3 уровня), длительность 1…600 мин
  (пусто → 30), цель, проект / локация / тип, статус Стек / Сегодня / Архив, отложенная дата,
  время создания и выполнения.
- **Алгоритм приоритета:** 4 частных скора и веса 0.45 / 0.35 / 0.10 / 0.10 — один в один
  с `PriorityCalculator.kt`, включая буст коротких задач после половины порога перегрузки.
- **7 режимов сортировки**, стартовый зависит от «умной сортировки».
- **Сегодня:** hero-блок нагрузки (минуты, число задач, шкала с отметками ½ и порога,
  статус «В норме / Плотно / Перегруз»), действия «Выполнить», «В стек».
- **Стек:** поиск по названию и цели, фильтры по локации и типу («все» / конкретная / «без»),
  счётчик с русской плюрализацией, светофор нагрузки, действия «В сегодня», «Удалить»
  (с подтверждением), «Отложить» (дата строго после сегодня; «До 5 июн»; фиолетовая обводка).
- **Объединённый режим** при выключенном разделении: вкладка «Задачи», одно действие «Выполнить».
- **Календарь:** месяц с понедельника, ячейка-«пончик» (равные секторы, радиус =
  `0.52 + (1 − e^(−d/60))·0.48`, цвета по правилам Android), режимы «Диапазон» / «Точка»,
  список задач выбранного дня, клик по названию месяца возвращает к сегодня.
- **Папки:** три оси, счётчики активных задач, системная папка «Без …», создание /
  переименование / удаление с отвязкой задач; экран задач одной категории с созданием
  задачи, в которой категория уже выбрана.
- **Форма:** создание и редактирование, видимость полей по настройкам, быстрое создание
  категории из пикера, валидация по уровню помощи (minimal / standard / advanced / custom).
- **Архив:** сортировка по времени выполнения, режим выбора, удаление выбранных и всего архива
  с подтверждением и точным числом.
- **Настройки:** тема, функции (отложенное планирование неактивно без разделения),
  режим календаря, уровень помощи и диалог обязательных полей, видимые поля, уведомления,
  коэффициенты с кнопками «По умолчанию» и «Сохранить», порог перегрузки и буст,
  контакты, поддержка проекта.
- **Онбординг:** 7 шагов, коэффициенты пропускаются без умной сортировки, поля задачи —
  без уровня «Свой», счётчик «Шаг N из M».
- **Утреннее уведомление** со списком задач на сегодня (до 5 + «и ещё N»).
- **Отложенные задачи** сами переходят в «Сегодня» в нужный день.

## 3. Адаптация под Mac

- Нижняя навигация → **сайдбар**: Сегодня, Стек/Задачи, Календарь, Архив и секции
  «Проекты / Локации / Типы» прямо в сайдбаре (как списки в Напоминаниях).
- Настройки → отдельное окно **⌘,** с вкладками. Плюс пункт в сайдбаре.
- Меню и шорткаты: ⌘N новая задача, ⌘1…⌘4 разделы, ⌘F поиск, **⌘Z отмена** любого действия
  с задачей (выполнение, удаление, перенос) — у Android этого нет.
- Уведомления: Mac не будит приложение по расписанию, поэтому при каждом изменении данных
  перестраиваются уведомления на 7 дней вперёд с точным составом (задачи «Сегодня» +
  отложенные, которые к тому дню перейдут). Клик по уведомлению открывает приложение.
- Перенос отложенных задач: при запуске, в полночь (`NSCalendarDayChanged`) и после сна.

## 4. Адаптивность

| Ширина контента | Поведение |
|---|---|
| Узкое окно | Сайдбар скрывается, карточки в одну колонку, hero вертикальный, календарь и список дня друг под другом |
| Среднее | Сайдбар виден, 1–2 колонки карточек |
| Широкое | Адаптивная сетка карточек (мин. ширина ~340 pt), hero в строку, календарь и список дня рядом |

Минимальный размер окна ~ 640 × 560.

## 5. Движение и материалы

- Пружины по умолчанию с критическим демпфированием (`response 0.35`, `damping 1.0`);
  с отскоком (`damping ~0.8`) — только там, где есть «импульс»: отметка выполнения, появление карточки.
- Вставка и удаление карточек — пружина + масштаб + прозрачность; перестановка при смене
  сортировки — анимированная раскладка сетки.
- Числа — `contentTransition(.numericText())`; шкала нагрузки — плавная заливка и смена цвета.
- Нажатие — мгновенное сжатие 0.97, наведение — лёгкий подъём и тень.
- Liquid Glass: сайдбар и тулбар системные, hero и плавающие элементы — `glassEffect`.
- Календарь: секторы «вырастают» при смене месяца, месяц сдвигается в сторону перехода.
- Тактильный отклик трекпада на выполнение (`sensoryFeedback`).
- «Уменьшить движение» → вместо сдвигов и пружин короткое растворение.

```
mac/
  project.yml
  KotaTaskMac/
    App/        точка входа, сцены, меню, состояние навигации
    Model/      Day, TaskItem, Category, перечисления
    Logic/      PriorityCalculator, TaskQueries, DayLoad, TaskValidator, CalendarMonth, RuFormat

    Services/   NotificationScheduler, DayClock
    Design/     палитра, пружины, общие компоненты
    Views/      Root, TaskCard, Today, Stack, Calendar, Category, Archive, TaskForm, Settings, Onboarding
    Resources/  Assets (иконка из Brand/logo4.png)
  KotaTaskMacTests/  Swift Testing: алгоритм, сортировки, фильтры, валидация, календарь, хранилище
```

## 7. Порядок работ

1. Каркас: `project.yml`, модель, логика, хранилище, настройки, юнит-тесты на чистую логику.
2. Оболочка и сайдбар, дизайн-система, карточка задачи, «Сегодня», «Стек», форма.
3. Календарь, папки, архив, настройки, онбординг.
4. Уведомления, смена дня и сон, иконка, меню.
5. Сборка, тесты, запуск и проверка вживую: светлая и тёмная тема, узкое и широкое окно.

## 8. Вне рамок

Синхронизация, облако, импорт/экспорт, виджеты, App Store и нотаризация.

## 9. Мелкие исправления Android-поведения (осознанно)

- Список дня в календаре показывает и отложенные задачи — как и ячейка (в Android расходятся).
- Начало дедлайна не может быть позже дедлайна.
- Шкала перегрузки нейтральная, когда контроль перегрузки выключен; тумблер есть в настройках.
